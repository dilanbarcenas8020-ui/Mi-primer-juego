# Guardián Estelar

Un juego de naves espaciales hecho con HTML y JavaScript, sin nada que instalar.

## Cómo jugar

Abre `index.html` en cualquier navegador.

- **Computadora:** flechas o WASD para moverte, Espacio para disparar, P para pausar.
- **Celular:** arrastra el dedo para mover la nave; dispara sola mientras tocas la pantalla.

Destruye asteroides y naves enemigas. Las estrellas doradas mejoran tu disparo (hasta 4 niveles) y las rosas te dan una vida extra. Cada 25 segundos sube el nivel y aparecen más enemigos.

## Publicarlo en internet (gratis)

1. En GitHub, entra a **Settings → Pages**.
2. En **Branch**, elige la rama donde está `index.html` y la carpeta `/ (root)`, y guarda.
3. En un par de minutos tu juego estará en `https://dilanbarcenas8020-ui.github.io/Mi-primer-juego/`.
